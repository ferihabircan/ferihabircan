### 🔭 Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**bayesflow-xai**](https://github.com/ferihabircan/bayesflow-xai) · [docs](https://ferihabircan.github.io/bayesflow-xai/) | Explainable AI for BayesFlow simulation-based inference. Three simulators (SIR, Lotka-Volterra, Gaussian Random Field) explained with Integrated Gradients, Saliency Maps, Attention Rollout and Masking, all behind one plugin registry. | Python · BayesFlow · Keras |
| [**chat_with_frida_kahlo**](https://github.com/ferihabircan/chat_with_frida_kahlo) | A persona chatbot that talks like Frida Kahlo, grounded with RAG and answering out loud through text-to-speech. | Gemini · LangChain · ElevenLabs · Gradio |

| [**insect-classifier**](https://github.com/ferihabircan/insect-classifier) | Image classifier that identifies insects from habitus photos, with a Gradio demo published to Hugging Face. | fastai · Gradio · Hugging Face |
